## 第三章 采购需求及技术规格

### 3.1 总体建设目标

本项目旨在对医院现有信息系统进行全面的升级改造，实现以下目标：
1. 建立统一的医院信息集成平台，实现各业务系统间的互联互通；
2. 建设临床数据中心，支持临床决策支持和运营数据分析；
3. 完善电子病历系统，满足国家电子病历分级评价四级要求；
4. 完成网络安全等级保护三级建设，通过等级测评。

### 3.2 主要建设内容

#### 3.2.1 HIS系统升级

| 模块 | 功能要求 | 数量 |
|------|---------|------|
| 门诊管理 | 实现门诊全流程信息化管理，日均门诊量支持≥8000人次 | 1套 |
| 住院管理 | 支持住院医嘱、护理、计费一体化管理 | 1套 |
| 药品管理 | 涵盖药库、药房、静脉配置中心管理，支持药品追溯 | 1套 |
| 物资管理 | 医用耗材、检验试剂、高值耗材全流程追溯管理 | 1套 |
| 财务管理 | 与HRP系统对接，实现业财一体化 | 1套 |

#### 3.2.2 EMR电子病历系统

系统应满足以下功能要求：
- 支持结构化电子病历书写，病历模板自定义功能；
- 实现病历质控，支持环节质控和终末质控；
- 支持病历三级审批流程；
- 提供病历检索、统计分析功能；
- 满足电子签名、时间戳等技术要求；
- 支持与HIS、LIS、PACS等系统深度集成。

#### 3.2.3 临床数据中心（CDR）

- 建立统一的数据标准化平台，实现异构系统数据整合；
- 支持临床数据浏览器，提供患者360度视图；
- 提供数据分析和报表工具，支持运营管理和临床科研。

#### 3.2.4 网络安全等级保护三级

| 安全域 | 建设内容 | 测评要求 |
|--------|---------|---------|
| 物理安全 | 机房改造、门禁、监控、动环监控 | 符合GB/T 22239-2019三级要求 |
| 网络安全 | 防火墙、入侵检测、网闸、日志审计 | 符合等级保护三级 |
| 主机安全 | 主机加固、数据库审计、漏洞扫描 | 符合等级保护三级 |
| 应用安全 | Web应用防火墙、安全开发规范 | 符合等级保护三级 |
| 数据安全 | 数据加密、备份恢复、数据脱敏 | 符合等级保护三级 |

### 3.3 系统性能要求

| 指标名称 | 要求值 |
|---------|-------|
| 系统可用性 | ≥99.9% |
| 核心业务响应时间 | ≤3秒 |
| 并发用户数 | ≥500 |
| 数据存储容量 | ≥50TB |
| 数据备份恢复时间 | ≤4小时 |

### 3.4 实施要求

1. 项目实施周期：合同签订后12个月内完成全部建设内容；
2. 投标人须提供详细的实施计划和项目管理方案；
3. 须配备具有相关项目经验的项目经理和实施团队；
4. 系统上线前须完成系统测试、性能测试、安全测试；
5. 试运行期不少于3个月。

### 3.5 培训要求

投标人应提供完整的用户培训和技术培训，包括：

## 第六章 评标办法

### 一、评标委员会

评标委员会由招标人代表和评审专家共5人组成，其中评审专家不少于成员总数的2/3。

### 二、评分标准

#### 6.2.1 价格分（30分）

价格分计算公式：
价格分 = （评标基准价/投标报价）× 30
其中，评标基准价为通过资格审查的投标人投标报价的最低值。

#### 6.2.2 技术分（45分）

| 评审因素 | 分值 |
|---------|-----|
| 系统功能完整性 | 15分 |
| 技术方案先进性 | 10分 |
| 实施方案可行性 | 10分 |
| 质量保障措施 | 5分 |
| 培训方案 | 5分 |

#### 6.2.3 商务分（25分）

| 评审因素 | 分值 |
|---------|-----|
| 公司综合实力 | 10分 |
| 类似项目业绩 | 8分 |
| 售后服务方案 | 7分 |

### 三、定标原则

评标委员会按综合得分由高到低顺序推荐中标候选人，综合得分相同的，价格低者优先。
