# 模型评测功能集成测试方案

## 1. 测试目标

对模型评测功能进行完整的集成测试，验证：
- ModelBenchmarkController 各接口功能
- ModelBenchmarkService 评测逻辑
- EvaluationReportService 报告生成逻辑
- WinRateCalculator 胜率计算逻辑
- TenderReviewMetricsRecorder 指标记录功能
- 整体数据流是否正确

## 2. 测试范围

### 2.1 ModelBenchmarkController 接口测试
| 接口 | 方法 | 测试内容 |
|------|------|----------|
| `/api/benchmark/run` | POST | 单模型评测 |
| `/api/benchmark/run-all` | POST | 批量评测（单模型/多模型/全部） |
| `/api/benchmark/results` | GET | 历史评测结果分页查询 |
| `/api/benchmark/models` | GET | 可用模型列表查询 |
| `/api/benchmark/prompt-templates` | GET | Prompt模板列表查询 |

### 2.2 ModelBenchmarkService 业务逻辑测试
- 单模型评测：验证调用链路、结果记录、错误处理
- 批量评测：验证多模型依次评测、结果汇总
- Provider解析：验证不同模型名对应正确的Provider
- Token估算：验证估算逻辑正确性

### 2.3 EvaluationReportService 报告生成测试
- 正常生成报告：给定有效taskId生成完整报告
- 空结果处理：pairResults为空时的处理
- 指标计算验证：
  - LLM评判指标计算正确性
  - 评分对比指标计算正确性
  - 风险一致性指标计算正确性

### 2.4 WinRateCalculator 胜率计算测试
- 胜负统计：BASELINE/CHALLENGER/TIE 计数正确
- 胜率计算：(challengerWins / (challengerWins + baselineWins))
- 评分差异：avgScoreDelta = sum(challenger-baseline) / n
- 风险一致性：相同风险等级的比例
- 建议判定：胜率>=0.5 且 avgScoreDelta>=0 则 PASS

### 2.5 TenderReviewMetricsRecorder 指标记录测试
- 会话生命周期：startSession -> record -> endSession
- LLM调用统计：次数和Token累加
- 规则命中记录：命中记录和豁免标记
- 阶段耗时追踪：各阶段时间记录
- 全局统计：全局计数器正确性

## 3. 测试用例设计

### 3.1 单元测试用例

#### WinRateCalculator 测试用例
```
Case 1: 正常胜率计算
- 输入: 10对结果, challenger胜3, baseline胜5, tie2
- 期望: challengerWinRate = 3/(3+5) = 0.375

Case 2: 全胜情况
- 输入: 5对结果, challenger胜5, baseline胜0
- 期望: challengerWinRate = 5/5 = 1.0, suggestion = PASS

Case 3: 评分差异计算
- 输入: baseline评分[80,85,90], challenger评分[85,82,88]
- 期望: avgScoreDelta = ((85-80)+(82-85)+(88-90))/3 = 0

Case 4: 风险一致性计算
- 输入: 4对, 其中3对风险等级相同
- 期望: consistencyRate = 3/4 = 0.75
```

#### EvaluationReportService 测试用例
```
Case 1: 完整报告生成
- 输入: 有效taskId, 多对评测结果
- 期望: 包含llmJudgeMetrics, scoreMetrics, riskMetrics, winRateStats

Case 2: 空结果处理
- 输入: taskId存在但无pairResults
- 期望: 返回报告但指标为0或null

Case 3: 总体建议判定
- 条件: winRate>=0.5 AND avgScoreDelta>=0 AND riskConsistency>=0.6
- 期望: overallSuggestion = PASS
```

### 3.2 集成测试用例（需要实际运行）
