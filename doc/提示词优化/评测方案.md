> 文档版本：v1.0

## 1. 评测概述

### 1.1 评测目标

本方案旨在建立一套完整、可量化的提示词评测体系，用于：
- 验证提示词优化的效果
- 确保系统输出质量稳定可靠
- 量化评估各场景的AI能力表现
- 为提示词迭代提供数据支撑

### 1.2 评测对象

| 评测对象 | 说明 |
|---------|------|
| 提示词模板 | System Prompt、User Prompt、Few-shot Examples |
| 场景工作流 | TenderReviewWorkflow、ContractPrecheckWorkflow、RiskAlertWorkflow |
| 结构化输出 | JSON格式的审查报告、风险等级判定 |
| 工具调用 | 文档解析、规则执行、证据组装等工具调用准确性 |

### 1.3 评测维度

| 维度 | 权重 | 核心指标 |
|------|------|---------|
| 回复质量 | 30% | 准确性、完整性、专业性 |
| 结构化输出准确率 | 25% | JSON解析成功率、字段完整率 |
| 工具调用准确率 | 25% | 正确调用率、参数准确率 |
| 用户满意度 | 20% | 任务完成率、复核通过率 |

## 2. 评测维度详细设计

### 2.1 回复质量评估

#### 2.1.1 准确性评估

**评估标准：**
- 风险等级判定与实际风险是否匹配
- 证据引用是否准确、无歧义
- 结论是否有明确的依据支撑

**评分规则（0-100分）：**
| 等级 | 分数 | 标准 |
|------|------|------|
| 完全准确 | 90-100 | 风险判定正确、证据充分、依据清晰 |
| 基本准确 | 70-89 | 风险判定正确、证据基本充分 |
| 部分准确 | 50-69 | 风险判定有偏差、但方向正确 |
| 不准确 | 0-49 | 风险判定错误或无依据 |

#### 2.1.2 完整性评估

**评估标准：**
- 是否覆盖所有关键风险点
- 报告结构是否完整（概览、风险项、管理建议）
- 证据是否完整（来源、内容、影响）

**评分规则（0-100分）：**
| 等级 | 分数 | 标准 |
|------|------|------|
| 完整 | 90-100 | 覆盖所有风险点，结构完整 |
| 基本完整 | 70-89 | 覆盖主要风险点，结构基本完整 |
| 部分完整 | 50-69 | 遗漏部分风险点 |
| 不完整 | 0-49 | 遗漏关键风险点或结构残缺 |

#### 2.1.3 专业性评估

**评估标准：**
- 术语使用是否规范（药监法规术语）
- 分析逻辑是否严谨
- 建议是否符合监管要求

**评分规则（0-100分）：**
| 等级 | 分数 | 标准 |
|------|------|------|
| 专业 | 90-100 | 术语规范、逻辑严谨、建议合规 |
| 基本专业 | 70-89 | 术语基本规范、逻辑基本严谨 |
| 一般 | 50-69 | 存在术语错误或逻辑缺陷 |
| 不专业 | 0-49 | 术语大量错误、逻辑混乱 |

### 2.3 工具调用准确率

#### 2.3.1 场景一：标书审查工具链

| 工具 | 调用条件 | 预期行为 |
|------|----------|----------|
| DocumentParser | 上传标书文件 | 正确解析文档结构 |
| TenderRuleEngine | 标书数据加载完成 | 执行12种规则检测 |
| TenderExemptionEngine | 规则命中后 | 正确应用免责判定 |
| RiskFusionService | 有效命中+免责结果 | 融合计算风险评分 |
| EvidenceAssembler | 风险融合完成 | 组装可解释证据 |
| ReportGenerationService | 所有前置步骤完成 | 生成结构化报告 |

**评估指标：**
- 工具调用正确率 = 正确调用次数 / 应有调用次数
- 工具调用顺序正确率
- 工具参数准确率

#### 2.3.2 工具调用典型错误模式

| 错误类型 | 描述 | 检测方法 |
|----------|------|----------|
| 遗漏调用 | 应有工具未被调用 | 检查步骤链路 |
| 错误调用 | 不需要时调用了工具 | 检查上下文 |
| 顺序错误 | 工具调用顺序不符合工作流 | 检查执行日志 |
| 参数错误 | 工具参数传递不正确 | 检查参数schema |

### 2.4 用户满意度

**评估方式：**
- 任务完成率 = 成功完成任务数 / 总任务数
- 复核通过率 = 专家复核通过数 / 提交复核数
- 问题闭环率 = 已解决问题数 / 发现问题数

- 每个测试用例至少3个参考答案

```
BLEU-4 >= 0.7: 优秀
BLEU-4 >= 0.5: 良好
BLEU-4 >= 0.3: 合格

### 5.2 自动化JSON输出验证

**验证流程：**

```python
class JSONOutputValidator:
    def __init__(self, schema_path: str):
        with open(schema_path) as f:
            self.schema = json.load(f)

    def validate(self, response_text: str) -> ValidationResult:
        # 1. 提取JSON（处理markdown代码块）
        json_str = self._extract_json(response_text)

        # 2. JSON解析验证
        try:
            obj = json.loads(json_str)
        except json.JSONDecodeError as e:
            return ValidationResult(success=False, error=f"JSON解析失败: {e}")

        # 3. Schema验证
        schema_errors = self._validate_schema(obj)

        # 4. 业务逻辑验证
        business_errors = self._validate_business_logic(obj)

        # 5. 综合判定
        if schema_errors or business_errors:
            return ValidationResult(
                success=False,
                errors=schema_errors + business_errors
            )
        return ValidationResult(success=True, parsed_object=obj)

    def _extract_json(self, text: str) -> str:
        """处理可能的markdown代码块包裹"""
        if "```json" in text:
            start = text.find("```json") + 7
            end = text.find("```", start)
            return text[start:end].strip()
        if "```" in text:
            start = text.find("```") + 3
            end = text.find("```", start)
            return text[start:end].strip()
        return text.strip()
```

### 5.3 优化前后对比方案

**A/B对比测试框架：**

```python
class ABComparator:
    def __init__(self, baseline_prompts: dict, optimized_prompts: dict):
        self.baseline = baseline_prompts
        self.optimized = optimized_prompts

    def run_comparison(self, test_cases: list[TestCase]) -> ComparisonResult:
        results = {
            "baseline": {"passed": 0, "failed": 0, "scores": []},
            "optimized": {"passed": 0, "failed": 0, "scores": []},
            "improvements": {}
        }

        for case in test_cases:
            # 使用baseline提示词测试
            baseline_result = self._run_single_test(case, self.baseline)
            results["baseline"]["scores"].append(baseline_result.score)
            if baseline_result.passed:
                results["baseline"]["passed"] += 1
            else:
                results["baseline"]["failed"] += 1

            # 使用optimized提示词测试
            optimized_result = self._run_single_test(case, self.optimized)
            results["optimized"]["scores"].append(optimized_result.score)
            if optimized_result.passed:
                results["optimized"]["passed"] += 1
            else:
                results["optimized"]["failed"] += 1

            # 计算单项提升
            results["improvements"][case.id] = {
                "score_delta": optimized_result.score - baseline_result.score,
                "passed_delta": int(optimized_result.passed) - int(baseline_result.passed)
            }

        # 汇总统计
        results["summary"] = self._calculate_summary(results)

        return ComparisonResult(**results)
```

|------|--------|--------|----------|

| BLEU-4均值 | A | B | +0.1 |
| 风险判定准确率 | C% | D% | +5% |

### 5.4 自动化评测脚本

**评测执行入口：**

```python
# evaluate.py
import argparse
import json
from datetime import datetime
from pathlib import Path

from evaluator import ABEvaluator, TestCaseLoader, ReportGenerator

def main():
    parser = argparse.ArgumentParser(description="医药监管AI提示词评测")
    parser.add_argument("--mode", choices=["single", "compare"], default="compare")
    parser.add_argument("--baseline-dir", type=Path)
    parser.add_argument("--optimized-dir", type=Path)
    parser.add_argument("--test-cases", type=Path, required=True)
    parser.add_argument("--output", type=Path, required=True)
    args = parser.parse_args()

    # 加载测试用例
    test_loader = TestCaseLoader()
    test_cases = test_loader.load(args.test_cases)

    if args.mode == "single":
        # 单版本评测
        evaluator = ABEvaluator(prompt_dir=args.baseline_dir)
        results = evaluator.evaluate(test_cases)
    else:
        # 对比评测
        comparator = ABComparator(
            baseline_prompts=args.baseline_dir,
            optimized_prompts=args.optimized_dir
        )
        results = comparator.run_comparison(test_cases)

    # 生成报告
    report_gen = ReportGenerator()
    report = report_gen.generate(results)

    # 保存结果
    with open(args.output, "w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)

    print(f"评测完成，结果已保存至: {args.output}")

if __name__ == "__main__":
    main()
```
